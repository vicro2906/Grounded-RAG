# Asistente sobre las guías de VIH (GeSIDA)

Responde consultas de manejo clínico del VIH **exclusivamente** a partir de las guías de
GeSIDA/SPNS, citando la sección y la frase literal que respalda cada recomendación.

**Cómo funciona la conversación**

- Los datos que menciones del paciente (gestación, función renal, coinfecciones, CD4…) se
  recuerdan durante la conversación para afinar las respuestas siguientes. Puedes verlos con
  **Datos recordados** y olvidarlos con **Paciente nuevo**.
- Si una consulta parece referirse a otro paciente, se pregunta antes de responder.
- Cada respuesta llega con lo que aún no se sabe del paciente planteado por ramas. Después
  puedes aportar esos datos para concretarla, o dejarla como está.
- Las tres preguntas de seguimiento son botones: un clic las formula.

**Herramienta de apoyo clínico; no sustituye en ningún caso el juicio del profesional
sanitario.** Prototipo de demostración: las respuestas no han sido revisadas por un clínico.
